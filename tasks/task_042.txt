# Details:
Create a structured client-side implementation for the Nuclei plugin, leveraging existing CoreAPI vulnerability views where appropriate:

1. Directory Structure:
   - Create `client/` directory with:
     - `plugin.js`: Main plugin registration
     - `routes.js`: Route definitions
     - `components/`: Directory for all UI components

2. Vulnerability Display Integration:
   - Leverage existing CoreAPI vulnerability views:
     - `project-view-vulnerabilities-dashboard.jsx` for dashboard display
     - `project-view-vulnerabilities-table.jsx` for tabular display
   - Ensure Nuclei-specific vulnerability metadata is properly formatted for these views
   - Add any Nuclei-specific display elements not covered by the generic views

3. Configuration Page:
   - Create a settings page for Nuclei configuration with:
     - Template selection options
     - Scan frequency settings
     - Target scope configuration
     - Advanced options toggle section

4. Enrichment Display Integration:
   - Implement a Nuclei enrichment display component
   - Register it with `PenPal.API.registerEnrichmentDisplay`
   - Ensure it follows the enrichment display API contract
   - Display relevant vulnerability data when an entity is enriched
   - Include Nuclei-specific details not covered in generic vulnerability views

5. UI Patterns:
   - Follow CoreAPI UI patterns for consistency
   - Use existing design components (buttons, cards, tables)
   - Implement responsive layouts that work on different screen sizes
   - Apply consistent error handling and loading states

Ensure all components use React best practices, including proper state management, component composition, and performance optimization. Focus on the Nuclei-specific aspects while integrating with the existing vulnerability display infrastructure.
