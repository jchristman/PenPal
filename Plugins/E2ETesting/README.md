# E2ETesting Plugin

## Purpose

The E2ETesting plugin provides a foundation for end-to-end testing in the PenPal framework, allowing plugins to register and execute E2E tests.

## Dependencies

- CoreAPI@0.1.0
- Docker@0.1.0
- JobsTracker@0.1.0

## Basic Usage

This plugin sets up the basic structure. Further functionality will be added in subsequent tasks.
